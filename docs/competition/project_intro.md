# 项目简介

## 完整名称

面向 ADAS 算法验证的 Zynq 软硬协同实时视觉平台——照片 HIL 与硬件安全岛

## 15 字以内名称

Zynq软硬协同ADAS平台

## 500 字以内简介

本项目基于 AMD ZYNQ-7010 构建面向 ADAS 算法验证的软硬协同实时视觉平台。系统采用 PS+PL 异构架构：PL 完成 OV5640 采集、彩色/灰度预处理、VDMA 视频通路、决策 FSM、500 ms 看门狗及声光控制；PS 基于 PYNQ/OpenCV 实现红绿灯圆形门控、车道虚实线分类、BEV、横向偏移与偏航报警、静态障碍物背景建模和目标跟踪，并驱动 LCD 叠加检测与告警信息。

作品采用照片 HIL 方法，使同一数据素材同时用于离线评测和现场实时演示。车道模式由 PL 完成 RGB→灰度预处理，PS 跳过重复颜色转换与灰度 HSV 计算，同场景吞吐由 19.54 提升至 20.52 FPS；当 PS 停止运行时，PL 可独立安全报警。系统通过 45 项测试，BSTLD 圆形灯留出集准确率 77.5%，TuSimple 虚实线留出集准确率 80%，实线和虚线控制样本均达到 12/12。项目配套提供 PYNQ 安全帧通路、性能统计、硬件调试清单和大模型协作 Skill，体现可复现验证、软硬协同与失效安全。

## 关键词

照片 HIL、软硬协同、硬件安全岛
